# Shockwave 1.1.2

## What's new

- Added a **Paste** (`paste`) checkbox to the widget: when enabled, the finished text is automatically pasted at the input cursor.
- Works with **clip+** to paste the combined clipboard text.
- Automatic paste is disabled by default. Set `auto_paste` under `[Text]` in `config/config.ini` to change its initial state.
